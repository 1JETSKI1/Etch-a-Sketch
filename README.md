# Etch-a-Sketch

A browser-based sketchpad built with vanilla JavaScript, HTML, and CSS.

## About

This project is part of [The Odin Project](https://www.theodinproject.com/) Foundations curriculum. The user can draw on a grid by hovering their mouse over squares, and resize the grid using the reset button.

## Features

- 16x16 default grid generated with JavaScript
- Hover effect that colors squares as you move your mouse
- Reset button that prompts for a new grid size (max 100x100)
- Grid always maintains 960px total size regardless of square count

## What I Learned

- DOM manipulation with JavaScript (createElement, appendChild, querySelector)
- Adding event listeners to dynamically created elements
- Using Flexbox to create a grid layout
- Calculating dynamic sizes based on user input
- Git workflow with regular commits

## How to Use

Open `index.html` in your browser, hover your mouse over the grid to draw, and click Reset to choose a new grid size.
